# 图片改为 WebP — 2026-11-16

状态：已上线。提交 `0a491f0` 已推到 `main`。181 张 JPG（23.71 MB）换成 WebP（18.10 MB），少 5.61 MB。质量 75；`zhidu/art/3` 在 75 时比原图大，改为 65；`earth/art/5` 改为 70。两张都小于原 JPG。

## 依据

2026-11-16 核对 `gewu-lab` `main`（`44624c7`）。仓库里没有 WebP 文件。JPG 约 23.7 MB，分布在 `img/`（31 张门户封面）和 17 个实验的 `art/`。引用是统一后缀，不能只转大图：

- 门户：`index.html` 的 `img/gw-*.jpg`、英雄图 `url("img/gw-hero.jpg")`，以及各实验页的 `og:image`。
- 纪录片图：各目录 `cine-data.js` 用 `art/` + 序号 + `.jpg`。战役沙盘在 `war/cine.js`，文件名是 `cp`、`jl`、`gd`、`cb`、`fs`、`tm`、`gm`、`cn`、`hs`，并会预载。
- 历史记录 `docs/changes/2026-11-15-*.md` 里的 `.jpg` 是当时的决定，不改写。

## 决定

1. `img/` 和各 `art/` 下每一张 JPG 都导出 WebP。长边大于 1600 的缩到 1600，不放大。质量 75。失败的一张都不删原图。
2. 代码里的图片路径从 `.jpg` 改为 `.webp`，包括首页注释里的新实验约定。旧变更记录不动。
3. 每一条新路径都要有对应文件之后，再删除已被替换的 JPG。
4. 不引入构建步骤。不改 three.js，不改实验正文。
5. README 补一句：门户封面和实验配图使用 WebP，新图不要再提交 JPG。
