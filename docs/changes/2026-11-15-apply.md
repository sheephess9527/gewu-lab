```js
  try { saved = JSON.parse(raw); } catch (e) { return; }
```

### 顶栏改成 `h1`

这些页没有 `h1`。把顶栏那个 `div` 换成 `h1`，class 不变，可见文字只留中文名。

`div.tname`：`yiguan`、`fenhe`、`zhidu`、`jindai`、`wenming`、`hanglu`、`gongye`、`geming`、`zhixu`、`weather`、`land`、`pro`、`line`、`cpro`。

例子：`<div class="tname">衣冠中国 · AttireLab</div>` 改为 `<h1 class="tname">衣冠中国</h1>`。

`div.ttl`：`cplx`、`seq`、`trig`。不要改 `contour/index.html` 里脚本生成的 `<p class="ttl">第 N 章`，那是章节标签，不是页标题。

例子：`<div class="ttl">复数 · ComplexLab</div>` 改为 `<h1 class="ttl">复数</h1>`。

这两类页面的基础规则目前没写桌面字号。在已有的 `.tname{...}` 和 `.ttl{...}` 规则里加上 `font-size:15px`。手机媒体查询里已有的 16px 保留。再加：

```css
h1.tname, h1.ttl { margin: 0; font: inherit; font-weight: 600; }
```

`font: inherit` 会盖掉上面的字号，所以不要用这条简写。用：

```css
h1.tname, h1.ttl { margin: 0; font-weight: 600; font-size: 15px; letter-spacing: -0.02em; }
```
