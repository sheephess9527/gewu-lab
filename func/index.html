图像变换

从基本函数 y = f(x) 出发，y = a·f(b(x − h)) + k 的图像可以由四步变换得到。

h 左右平移（“左加右减”），k 上下平移，a 纵向伸缩（a < 0 时还要关于 x 轴翻折），b 横向伸缩为原来的 1/b。

淡色是原函数，圆点标出一个特征点在变换前后的位置。拖动平移，滚轮或双指缩放。

y = aˣ 与 y = logₐx（a > 0 且 a ≠ 1）互为反函数，它们的图像关于直线 y = x 对称。

指数函数恒过 (0, 1)，对数函数恒过 (1, 0)。a > 1 时两者都递增，0 < a < 1 时都递减。

拖动曲线 aˣ 上的点 P，它关于 y = x 的对称点 Q 始终落在 logₐx 上。

角 θ 的终边与单位圆交于 P(cosθ, sinθ)：纵坐标是 sinθ，横坐标是 cosθ。

把 P 的高度随 θ 记录下来，就展开成正弦曲线。转一圈是 2π，所以周期是 2π。

可以暂停后拖动点 P，手动改变 θ。

y = A sin(ωx + φ) + k：A 决定振幅，ω 决定周期 T = 2π/ω，φ 决定初相，k 让图像上下平移。

从 y = sin x 出发，先向左平移 φ 得 y = sin(x + φ)，再把横坐标缩短为原来的 1/ω；若先伸缩得 y = sin ωx，则只需平移 φ/ω。

淡色是 y = sin x，青绿是变换后的图像。打开“五点法”可看一个周期内的五个关键点。

割线 PQ 的斜率 (f(x₀ + h) − f(x₀)) / h 是 f(x) 在 [x₀, x₀ + h] 上的平均变化率。

h → 0 时，Q 沿曲线滑向 P，割线趋近切线；切线的斜率就是导数 f′(x₀)。

拖动点 P 改变 x₀，拖 h 滑块或点“h → 0”看割线如何转向切线。

上图是 f(x)，下图是导函数 f′(x)，两图共用 x 轴。

f′(x) > 0 的区间上 f(x) 单调递增（青绿），f′(x) < 0 的区间上单调递减（红）。

f′(x) 由正变负的点是极大值点 ▲，由负变正的点是极小值点 ▼；f′(x₀) = 0 但不变号的点（如 x³ 在 0 处）不是极值点。

拖动竖直游标看各处的 f(x)、f′(x) 与切线；拖空白处平移，滚轮或双指缩放 x 轴。

教材：人教A版 必修第一册·第四章 4.5 函数的应用（二）

函数零点就是 f(x) = 0 的实数根，也是图像与 x 轴交点的横坐标。

零点存在定理：f 在 [a, b] 上连续且 f(a)·f(b) < 0，则 (a, b) 内至少有一个零点。

二分法每步取中点 m，保留端点异号的一半，区间缩小一半。拖动竖线 a、b 设定初始区间。

教材：人教A版 选择性必修第二册·第五章 一元函数的导数及其应用（拓展阅读，现行高考不作要求）

把 [a, b] 分成 n 等份，每份取一点 ξᵢ 作高，用 n 个矩形面积之和 Sₙ = Σ f(ξᵢ)·Δx 近似曲边梯形的面积。

n → ∞ 时，黎曼和 Sₙ 趋于定积分 ∫ₐᵇ f(x)dx；在 x 轴下方（f < 0，红色）的部分计为负。

微积分基本定理：若 F′(x) = f(x)，则 ∫ₐᵇ f(x)dx = F(b) − F(a)。拖动竖线 a、b 改变区间。
